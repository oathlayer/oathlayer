# Oathlayer

**Trust is everything.** Oathlayer is an independent check on AI answers. It checks each answer against independent sources, gives it a clear verification tag, and records it with a permanent doc number that anyone can look up for free.

Oathlayer reports what happened. It does not judge right or wrong for you. It works on any topic and with any AI model.

## Ways to use it

- **Oathlayer Chat** at [oathlayer.com](https://oathlayer.com): ask a question or paste up to 5 legal citations and get a clear table of results. No programming needed.
- **API** for your own apps: [oathlayer.com/docs](https://oathlayer.com/docs)
- **AI agents (MCP):** connect to `https://mcp.oathlayer.com` and use the `verify_output` tool.

## The Five Pillars of Trust

| Tag | Meaning |
| --- | --- |
| Verification Successful - Oath Approved | Passed the verification threshold. |
| Verification Threshold Not Met | A strong answer that did not pass the threshold. Double check it. |
| Various Perspectives Apply | A valid answer exists, but reasonable people may see it differently. |
| Complex Question - Threshold Reserved | Needs specialist knowledge. An answer is given, but the threshold is reserved. |
| Clarity Needed to Continue | The question is too unclear to check. Ask again with more detail. |

## Citation Checks

Paste a case citation and Oathlayer checks it against official court sources. Each citation gets a short tag:

| Short tag | Meaning |
| --- | --- |
| **Confirmed** | Found on official court or government sources. |
| **Unofficial** | Found, but only on unofficial sites. Check it before relying on it. |
| **Mismatched** | Part of the citation does not match the real case. The correct version is shown. |
| **Not found** | Cannot be found in available sources. |

If trusted sources report that a case has been overruled, the result also shows *Reported overruled*.

This checks the citation only, not whether the case supports your argument.
