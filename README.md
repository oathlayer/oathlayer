# Oathlayer

AI trust infrastructure. Verify AI outputs before anyone acts on them.

Every answer checked against real sources. Every answer documented with a permanent doc number anyone can verify for free.

## What it does

- Checks any AI answer against independent real-world sources, not just legal
- Returns a clear trust signal: Verification Successful (Oath Approved), Verification Threshold Not Met, Various Perspectives Apply, Complex Question (Threshold Reserved), or Clarity Needed to Continue
- Legal citations get their own check: confirmed on official sources, found only on unofficial sites, mismatched with the correct citation shown, or not found in available sources
- Every answer gets a unique permanent doc number
- Anyone can verify any doc number free at oathlayer.com/verify
- Works on any AI model
